# Project reports

This directory presents the public technical assessment of **DUAL-STATION SDR SPECTRUM MEASUREMENT**, conducted by the Faculty of Applied Informatics, Tomas Bata University in Zlín, within the ESA Spectrum Sharing Makerspace programme.

| Document | Contents |
| --- | --- |
| [Project evaluation](project_evaluation.md) | Objectives, measurement coverage, principal results, interpretation, limitations, published outputs, and technical opportunities for further work |

The assessment covers the campaigns of **18–30 September 2026** and **16–25 October 2026**, with PPS-assisted paired frame analysis for **25–30 September 2026**. The urban site showed substantially more detected broadband peaks and stronger daytime degradation of SNR and frame recovery than the rural reference. The observations support a terrestrial-interference hypothesis, including a possible contribution from adjacent-band 5G networks, without identifying the transmitters or proving the coupling mechanism.

This directory contains a public scientific and technical assessment. The full contractual report submitted to ESA is distributed separately and is not included here.
