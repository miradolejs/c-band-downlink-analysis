# Noise statistics: 16–25 October 2026

Merged noise-level results for both stations. `Median_Noise_dB` is the median of the logarithmic mean-bin-power time series, and `Noise_Std_dB` is its standard deviation in dB. The supplied processing configuration uses the RF reference band 3836.5–3837.5 MHz and ten five-second chunks beginning at offset 5 s.

The dBFS reference describes the recorder digital scale, rather than calibrated RF input power in dBm. This dataset supplies the noise reference used in the SNR and temperature/noise workflows.

Processing workflow: [analyze_noise_statistics_dbfs.m](../../../analysis/noise_statistics/analyze_noise_statistics_dbfs.m). The MAT dataset retains analysis settings and separate station results. Figures are provided in PNG for viewing and MATLAB FIG for further inspection. The date interval identifies the result set; it does not independently establish uninterrupted acquisition or successful processing of every scheduled recording.
